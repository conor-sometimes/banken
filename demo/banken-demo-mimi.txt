This is the narrated transcript the demo prints (ANSI colour and the VM boot log stripped). It is a
real run, not a mock-up: the same command reproduces it on any host with KVM and the mimi input.
The arc is: catch the reverse shell -> deliver it to the SIEM -> silence on a normal day's work.

Note the [siem] step: banken --watch reliably delivers OCSF findings to the mock SIEM over HTTP (see
the auditd flavour, which POSTs the reverse_shell body itself), but in this mimi-only run only the
boot-time kernel_module_load finding reached the webhook; the headline reverse_shell is proven by
the [alert] and [stream] beats (jsonl finding + the exec in mimi's capture stream), which are the
asserted gate. The webhook delivery of the stream-sourced reverse_shell is a known rough edge
flagged for the sink owner.
